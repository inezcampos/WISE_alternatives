# WISE_alternatives
Data sources and interactive visualisations on pluriversal alternatives and policy documents.


**WISE** stands for "Wellbeing, Inclusion, Sustainability and the Economy". It is a post-economic growth framework. This repository contains research data and interactive visualisations developed as part of the research on **pluriversal alternatives** and **WISE policy documents**.

## Repository structure

### Data
The `data/` folder contains the Excel spreadsheets with the source data used in the research.

### Interactive visualisations
The `visualisations/` folder contains two interactive HTML treemaps that resulted from the analysis:

- `treemap_pluriversal_alternatives_keywords.html` — Keyword visualisation of pluriversal alternatives.
- `treemap_policy_documents_keywords.html` — Keyword visualisation of policy documents.

## Access and use

This repository is currently private while the associated research article is under preparation. Further information on data sources, methodology and reuse conditions will be provided alongside publication.
